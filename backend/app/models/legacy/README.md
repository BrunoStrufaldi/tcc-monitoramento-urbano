# Modelos legados — fase avançada do TCC

Estes modelos SQLAlchemy correspondem ao schema estendido (`database/schema_extended.sql`)
com regiões, localizações, evidências visuais, notificações e logs.

**Não são usados na fase atual** (fundação com tabela `eventos` simplificada).
Serão reativados quando as tabelas estendidas forem aplicadas ao banco.

YOLO e integração completa de Data Fusion dependem desta fase.
